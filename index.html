HoverZoom

Privacy Policy

Last updated: October 5, 2026

This policy describes HoverZoom version 1.2.1, a Chrome extension that enlarges images on hover on websites chosen by the user.

Information used by the extension

HoverZoom processes the current website's address to determine its domain and apply the user's settings. On authorized, enabled sites, it reads image elements, image addresses, relevant image links and CSS background images to display an enlarged preview. It processes pointer position and relevant page interactions, such as scrolling and the Escape key, to position or dismiss that preview. This processing takes place locally in the browser; these interactions are not recorded as an activity log.

HoverZoom reads the browser interface language to select its packaged interface translation.

Local storage and retention

HoverZoom stores configured domain names and their enabled state, preferred preview size and hover delay using Chrome's local extension storage. It does not use Chrome Sync for these settings. Settings remain until the extension's local data is cleared or the extension is uninstalled. Switching a domain off does not delete its saved preferences.

The extension does not maintain a browsing-history timeline or save image files. Preview data is used temporarily in memory. Chrome may cache images as part of its normal operation.

Network requests and sharing

HoverZoom has no developer-operated data collection endpoint and sends no browsing data, images, settings or interaction logs to the developer. It contains no advertising, analytics or tracking services and does not sell user data.

Displaying a preview may cause the browser to request an image, including a larger version, from the image address supplied by the webpage. The website or image host may receive ordinary network information, such as the user's IP address and browser-managed request headers, referrer or cookies, subject to browser policies. These requests are used only to display the requested image and are subject to the image host's own practices. HoverZoom does not read authentication cookies or upload images to a separate service.

Permissions and user control

HoverZoom starts disabled. When the user opens the extension on a site, it can request optional access to that site's domain and subdomains. Granting access does not itself enable zoom; the user controls the ON/OFF setting. Switching an enabled domain to OFF stops zoom and removes its optional host permission. Users can also manage site access or remove the extension in Chrome.

The activeTab permission identifies the current site following a toolbar interaction. The storage permission saves local preferences. The scripting permission runs packaged preview code on authorized, enabled sites. Optional host permissions allow the feature to work on the websites selected by the user across page visits.

Limited use and executable code

Information handled by HoverZoom is used only to provide its image preview feature and related settings. It is not used for advertising, profiling, creditworthiness or lending decisions. All executable extension code is included in its installation package; the extension does not download or execute remote code.

Changes

This policy will be updated when the extension's data practices change. Its update date identifies the current policy.
